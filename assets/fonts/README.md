`NotoSansSC-GB2312.ttf` is a subset of Noto Sans CJK SC Regular
(© 2014-2021 Adobe, SIL Open Font License 1.1, see `OFL.txt`), taken from Debian
`fonts-noto-cjk` 1:20240730 and rebuilt with `scripts/build-cjk-font.py`:
ASCII/Latin-1, general punctuation, CJK symbols, full-width forms and all
GB2312 characters, with outlines converted to TrueType. fillable-pdf/1 embeds
only the glyphs a filled form uses.
