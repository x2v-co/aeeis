# AEEIS 多 Bot 工作室 · 交互 Demo

这是交互设计稿 [`../2026-10-21-aeeis-interaction-design.md`](../2026-10-21-aeeis-interaction-design.md) 的可运行原型：**频道 = 项目，Bot 是同事，任务在消息流里被交接，人只在需要决定时出现。**

## 运行

直接双击 `index.html`，或：

```bash
cd docs/design/demo
python3 -m http.server 4173
# http://127.0.0.1:4173/
```

无构建步骤、无依赖、无后端。数据全部在 `app.js` 里，刷新即重置。

## 五分钟走查

1. 默认「发布协作」：看一句话如何被小安拆成任务，以及“小安 → 阿研”的交接卡。
2. 审批卡点 **批准**：卡片变为已批准，收件箱从 2 变 1。
3. 提问卡点 **周三**：卡片变为已确认，收件箱清零。
4. 切 **增长实验** → 点失败卡 **重试 2 条**：失败恢复，任务板顶部失败筛选条变为“无失败任务”。
5. 顶部 **任务板**：6 列 + 顶部失败筛选条；点卡片看任务抽屉、证据、交接链。
6. 顶部 **工作室**：工位、交接路径、正在发生 / 需要你 / 回放。
7. `⌘K` / `Ctrl+K`：搜“阿研”看 Bot 档案，或跳到频道/任务。
8. 输入框发一句话：小安 thinking → 本地回复 + 新任务（模拟，不调用模型）。
9. 缩到 390px：频道和团队变成抽屉，任务板横向滚动，工作室提示桌面可用。

## 直达状态

- `?channel=growth` / `?channel=feedback`
- `?studio=1` / `?board=1` / `?inbox=1`
- `?tab=tasks` / `?tab=files`
- `?drawer=task` / `?drawer=bot`

可组合，例如 `index.html?channel=growth&board=1`。

## 文件

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架 |
| `styles.css` | token、布局、卡片、响应式、动效 |
| `app.js` | 样例数据、渲染、交互 |
| `screenshots/` | 桌面 / 移动 / 工作室 / 收件箱 / 任务板预览 |

## 边界

这是交互原型，不是 runtime 集成：没有真实模型调用、持久化、登录、权限校验、文件上传、拖拽改状态、side thread、RSI；工作室回放只是重放一次交接动效。字体走 Google Fonts，离线时回退系统字体。

设计细节见主文档 §5–§10，以及新增的 §22「可交互 Demo」。
